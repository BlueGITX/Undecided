# MindLend

MindLend is a peer-to-peer skill exchange platform that allows users to teach skills they know in exchange for learning skills from other users.

## Project Goal

The goal of MindLend is to provide an accessible way for people to learn new skills without requiring traditional paid courses or tutoring.

## Planned Features

- User registration and login
- User profiles
- Skills offered and wanted
- Skill and user search
- Exchange requests
- Messaging
- Reviews and ratings

## Architecture

MindLend will follow the Model–View–Controller (MVC) architecture.

- **Model** — Handles application data and database interactions.
- **View** — Handles the user interface.
- **Controller** — Processes user actions and connects the View with the Model.
